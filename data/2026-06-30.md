Method: 采用Decode-and-Forward网络编码协作（OTFS-NCC）框架，运行于五节点TDD拓扑；使用增强型高斯近似消息传播算法（GA-MPA）抑制误差传播；设计硬件-算法解耦的GPU架构，采用一维内存映射和超越函数截断，将基带速率提升至2 MHz。

Result: 频谱效率相比传统中继提升33%；模拟实时因子（RTF）从4.37压缩至0.89；在3GPP EVA70衰落信道下，112×64 DD网格上实现60秒连续零丢包实时解调。

Conclusion: 所提出的OTFS-NCC原型系统成功实现了实时协作OTFS通信，验证了GPU加速方案在复杂DD域处理中的有效性，为6G车联网实际部署提供了可行架构。

Abstract: While Orthogonal Time Frequency Space (OTFS) modulation offers robust reliability for 6G vehicular networks, standalone links suffer from blockages, and existing Software-Defined Radio (SDR) testbeds are bottlenecked by complex Delay-Doppler (DD) equalizers. This paper presents a real-time Decode-and-Forward Network-Coded Cooperation OTFS (OTFS-NCC) prototype implemented on consumer hosts and USRP B210 SDRs. Operating over a five-node TDD (Time-Division Duplexing) topology, our framework improves spectral efficiency by 33% over conventional relaying while mitigating error propagation via an enhanced Gaussian Approximate Message Passing Algorithm (GA-MPA). To support a 2 MHz baseband rate, we devise a hardware-algorithm decoupled GPU (Graphics Processing Unit) architecture using 1D memory mapping and transcendental function clipping, compressing the simulated Real-Time Factor (RTF) from 4.37 to 0.89. RF-conducted Hardware-in-the-Loop validation under 3GPP EVA70 (Extended Vehicular A model) fading confirms sustained zero-packet-drop real-time demodulation over 60-second test runs across a large 112-by-64 DD grid.
